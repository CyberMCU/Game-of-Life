# Game-of-Life
## Originally made by [Conway](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life)

---

This little program was originally made for a STM32 with LED Drivers and LED Matrix.

The number of step is located in the main.cpp file.
If you want to change the initial pattern, you need to go in the setup function of gameClass.cpp.

If you want to change the size of the grid, you need to go in the gridClass.hpp and change the value of size.
The default is 15.

Enjoy  ;-)
